# Song Popularity Prediction & User Recommendation

Predicts whether a Spotify track falls in the top streaming quartile and recommends similar songs from audio features.

## Models
- Logistic Regression
- Tuned Random Forest (GridSearchCV)
- SVM
- KNN
- Decision Tree
- XGBoost
- Tuned MLP (neural network)

## Extra
- SHAP explanations for Random Forest
- Cosine-similarity song recommender from user-entered features

## Run
Open `Song_Popularity_Prediction_And_User_Recommendation_System.ipynb` in Colab/Jupyter with the Spotify Most Streamed Songs dataset.
