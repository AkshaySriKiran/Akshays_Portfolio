# Video Game Popularity Prediction

Machine learning notebook that predicts video game popularity from publisher, genre, platform, user score, and ratings.

## Models
- Support Vector Machine
- K-Nearest Neighbors
- Decision Tree
- Random Forest
- XGBoost

## Pipeline
Feature engineering → SMOTEENN class balancing → standardization → polynomial features → Random Forest feature selection → model training & evaluation.

## Run
Open `game_popularity_prediction.ipynb` in [Google Colab](https://colab.research.google.com/) or Jupyter and upload the cleaned video games CSV used by the notebook.
