## Preview locally

```bash
python3 -m http.server 8000
```

Open http://localhost:8000

## Publish to a new GitHub repo

From this folder on your Mac (with `gh` logged in):

```bash
bash scripts/publish-to-github.sh
```

Then enable Pages: repo **Settings → Pages → Deploy from branch `main` / (root)**.
